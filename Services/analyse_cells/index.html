Информация и Инструкция

Как получить данные из WMS Navision

  1. Откройте WMS Navision На главной странице WMS Navision нажимаем «Управление ячейками»
  2. Экспорт Экспортируем в Excel через боковое меню, подменю «Печать и отправка», и сохраняем файл в удобное место в формате xlsx. Если файл сохраняется не как xlsx, то повторяем операцию и нажимаем открыть, после чего пересохраняем в удобном месте.
  3. Загрузите файл Перетащите выгруженный файл в область загрузки выше или кликните для выбора.
  4. Выберите зоны В открывшемся окне отметьте зоны для загрузки - в отчёт попадут только они.

Сохранение данных

Данные хранятся локально в браузере (IndexedDB) до ручной очистки. При обновлении страницы данные сохраняются.

📊
Аналитика

Поиск ячеек с пустой наполненностью для быстрого анализа корректности складского стока.

📥
Экспорт

Выгрузка результатов в Excel с форматированием, условным форматированием и фильтрами.

🔒
Безопасность

Все данные обрабатываются локально в вашем браузере и не передаются на внешние серверы.

Важно знать

Без размера - ячейка для многопаллетного хранения на одном адресе.

Подбор из кучи - разрешён подбор любой паллеты с идентичным артикулом и количеством. Отмечены бейджами в таблице.
