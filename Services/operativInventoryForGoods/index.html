📋 Информация и инструкция

📥 Как получить отчёт

  1. Откройте WMS Navision Перейдите в Подразделения → Склад.
  2. Найдите отчёт Откройте Отчёт по проведённым оперативным инвентаризациям по товару.
  3. Выгрузите данные Сохраните отчёт в Excel (.xlsx или .xls).
  4. Загрузите файл Перетащите его в область загрузки или выберите через проводник. Данные обработаются локально в браузере.

Дополнительно

Строки - все записи отчёта, артикулы - уникальные коды товара.
Дельта количества = Фактическое Кол-во - Расчетное Кол-во. Отрицательная дельта - недостача, положительная - излишек.
Дельта суммы = Факт Сумма - Расчётная Сумма, в рублях. Показывает денежный масштаб расхождения.
2-й подсчёт - повторный ввод количества. Показывает, сколько строк пересчитывали.
Длительность = время завершения последней строки - время назначения первой строки ведомости.
Дата периода - дата завершения подсчёта; для незавершённых строк используется дата назначения.
