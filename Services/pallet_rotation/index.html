Информация и Инструкция

Как получить данные из WMS Navision

  1. Откройте WMS Navision Главное окно
  2. Перейдите по ссылке Нажмите на ссылку Паллеты
  3. Выделите данные Нажмите на любое место в списке и выделите всё с помощью сочетания клавиш Ctrl+A
  4. Скопируйте данные Нажмите сочетание клавиш Ctrl+Shift+C и дождитесь завершения копирования
  5. Выгрузите данные Создайте новый файл Excel и вставьте данные сочетанием кнопок Ctrl+V
  6. Сохраните файл Сохраните выгруженный файл в удобном месте на компьютере
  7. Загрузите в инструментПеретащите файл Ваш_файл.xlsx в область загрузки, либо вставьте нажатием на область загрузки через проводник
  8. Примените фильтрыОтметьте если необходимо имеющиеся пункты для дополнительной фильтрации данных.

Сохранение данных

Данные хранятся локально в браузере (IndexedDB) до ручной очистки. При обновлении страницы данные сохраняются.

📊
Аналитика

Автоматический расчёт срока хранения, определение паллет с нарушением ротации.

📥
Экспорт

Выгрузка результатов в Excel с форматированием, условным форматированием и фильтрами.

🔒
Безопасность

Все данные обрабатываются локально в вашем браузере и не передаются на внешние серверы.

Важно знать

Экспорт из WMS Navision не всегда корректно работает при выгрузке большого количества строк, поэтому для надёжности необходимо использовать стандартные средства буфера windows через принудительное копирование всех строк.

Система обрабатывает паллеты по колонке «Хранение (дней)» из загруженного файла.

Перед вставкой в таблицу необходимо отформатировать столбец где будут находиться sscc в текст, обычно это столбец E. Это необходимо чтобы внешние длинные sscc праильно отображались.

  • 🟢 Норма: до 15 дней хранения.
  • 🟡 Внимание: 15-30 дней хранения.
  • 🟠 Критично: 30-60 дней хранения. Требует немедленного внимания.
  • 🔴 Очень критично: 60-90 дней хранения.
  • 🟣 Критическое застояние: 90+ дней хранения.
