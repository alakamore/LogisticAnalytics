📥 Как получить данные из WMS Navision

  1. Откройте WMS Navision Глваное окно
  2. Перейдите по ссылке Нажмите на ссылку Содержимое ячеек (расширенное)
  3. Откройте вкладку действий Нажмите на вкладку Действия в верхней панели
  4. Запустите отчёт Нажмите на отчёт Пополнение основного адреса
  5. Настройте фильтр В поле Тип зоны фильтр выберите необходимую зону
  6. Выгрузите данные Нажмите OK и сохраните файл в формате Excel
  7. Сохраните файл Сохраните выгруженный файл в удобном месте на компьютере
  8. Загрузите в инструмент Перетащите файл Ваш_файл.xlsx в область загрузки, либо вставьте нажатием на область загрузки через проводник
  9. Выберите нужные зоны для анализа Выберите все зоны или только необходимые

Сохранение данных

Данные хранятся локально в браузере (IndexedDB) до ручной очистки. При обновлении страницы данные сохраняются.

📊
Аналитика

Автоматический расчёт наполненности, определение потребности в пополнении и поиск источников.

📥
Экспорт

Выгрузка результатов в Excel с форматированием, условным форматированием и фильтрами.

🔒
Безопасность

Все данные обрабатываются локально в вашем браузере и не передаются на внешние серверы.

⚠️ Важно знать

Если артикул имеет основной адрес но у него не установлен максимальный запас, то такой артикул можно исключить из выборки. Это облегчит анализ для выявления потребности пополнения основных адресов только для контролируемых артикулов. Предварительно в Navision можно убрать максимальный запас у артикулов с топ EM.

  • 🏠 Основной адрес - где должен храниться товар
  • 📍 Источники - адреса с фактическим количеством
  • 📊 Наполненность % = (В основном / Макс. Запас) × 100%
  • ✅ SKU - уникальные артикулы
