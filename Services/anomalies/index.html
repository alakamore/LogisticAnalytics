📋 Информация и инструкция

📥 Как получить данные

  1. Отчёт 1 - «Список аномалий запаса» Выгрузите список аномальных артикулов из Power BI: Экспорт в Excel. В файле нужны колонки «Артикул», «В торговом зале», «C3» и «Экспо».
  2. Отчёт 2 - выгрузка из содержимое ячеек В WMS Navision откройте Содержимое ячеек (расширенное), выделите данные Ctrl+A и скопируйте их Ctrl+Shift+C.
  3. Сохраните выгрузку Вставьте данные в новый файл Excel (Ctrl+V), заранее отформатируйте столбец SSCC как текст и сохраните файл.
  4. Загрузите оба отчёта Перетащите файлы в области загрузки. Анализ запустится только после загрузки обоих отчётов - или нажмите «Загрузить пример из папки src».

🔗 Как работает слияние

  1. Сопоставление по коду Артикул из отчёта 1 ищется в отчёте 2 по колонке LM Код.
  2. Адреса хранения Для найденного артикула показываются все адреса: зона, ячейка, основной адрес, тип ячейки, наличие, свободно, в подборе, паллета и сумма.
  3. Отклонения по магазину «В торговом зале», C3, экспо и отрицательная доступность показываются отдельно и не суммируются между собой.
  4. Позиции без находок Артикулы, которых нет на складе, отделены в списке разделителем «❓ Не найдены на складе» - искать их физически негде.

Сохранение данных

Отчёты хранятся локально в браузере (IndexedDB) до ручной очистки и восстанавливаются после перезагрузки страницы.

Работа с адресами

Безопасность

Все данные обрабатываются локально в вашем браузере и не передаются на внешние серверы.

⚠️ Нужны оба отчёта

Пока загружен только один файл, показатели и список не строятся: без содержимого ячеек нельзя определить, где физически лежит аномальный артикул.

📄 SSCC - текстом

При вставке выгрузки WMS отформатируйте столбец SSCC как текст. Иначе длинные номера искажаются и становятся не актуальными при разборе.
