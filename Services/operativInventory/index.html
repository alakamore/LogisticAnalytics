📋 Информация и инструкция

📥 Как получить отчёт

  1. Откройте WMS Navision Перейдите в Подразделения → Склад.
  2. Найдите отчёт Откройте Отчёт по проведённым оперативным инвентаризациям.
  3. Выгрузите данные Сохраните отчёт в Excel (.xlsx или .xls).
  4. Загрузите файл Перетащите его в область загрузки или выберите через проводник. Данные обработаются локально в браузере.

Дополнительно

Строки - все записи отчёта, артикулы - уникальные коды товара.
Дельта = Результат подсчёта − На начало подсчёта.
Оборот расхождений = сумма абсолютных дельт, шт.
Длительность = время учёта − время назначения. Считается только для завершённых ведомостей со статусом Учтено.
Дата периода - дата учёта. Для ведомостей В процессе используется дата назначения, чтобы они не выпадали из периода.
