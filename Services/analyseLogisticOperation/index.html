📖 Как работает сервис

📥 Загрузка файла

  1. Power BI → 001 Логистические операции → Производительность сотрудников по операциям с товаром.
  2. Вкладка Data: выберите магазин и период, дождитесь загрузки таблицы.
  3. Меню таблицы → Экспортировать данные → .xlsx. Загрузите файл в сервис.

Заголовки сервис находит сам. Обязательные колонки: дата, время, операция, контекст, количество операций, количество штук и ФИО.

💡 Показатели простыми словами

  • Операции - сколько операций выполнено за период.
  • Штуки - сколько единиц товара обработано. На КПД не влияют.
  • Взвешенные операции - операции с поправкой на трудоёмкость: SKU считаются тяжелее паллет и заказов.
  • Активный слот - 10-минутный интервал, в котором была хотя бы одна операция.
  • КПД - скорость работы: сколько взвешенных операций сотрудник делает за активный слот.

📦 Контекстная продуктивность

Вкладка «Контекстная продуктивность» показывает, сколько паллет, штук SKU, сборок и заказов сотрудник обрабатывает за час активной работы в своём контексте.

  • Паллеты - Σ «Кол-во операций» по строкам с контекстом pallet: одна операция = один паллет.
  • Штуки SKU - Σ «Кол-во штук» только по строкам с контекстом sku.
  • Сборки - Σ «Кол-во операций» только по операции «Сборка в заказы».
  • Заказы - Σ «Кол-во операций» по строкам с контекстом order.
  • Активные часы - уникальные слоты (ЛДАП, дата, 10-минутный интервал) × 10 / 60. Перерывы и простои не входят.
  • Паллет/ч - паллеты / активные часы паллетных строк; Штук SKU/ч - штуки SKU / активные часы SKU-строк; SKU/ч - SKU-операции / активные часы SKU-строк; Сборки/ч - сборки / активные часы строк операции «Сборка в заказы»; Заказы/ч - заказы / активные часы строк контекста order.
  • Часы контекстов пересекаются: один слот может содержать pallet, sku, order и сборки, поэтому их нельзя суммировать как общий знаменатель.
  • Ставка показывается от 3 активных слотов контекста, иначе «—», а не 0.
  • Топ-10 сортируется по паллетам/ч, SKU/ч, штукам SKU/ч, паллетам, штукам, сборкам, сборкам/ч, заказам и заказам/ч; на него влияют только фильтры над топ-10 и порог активных слотов.
  • Таблица фильтруется независимо от топ-10: фильтры над топ-10 не меняют таблицу, и наоборот.
  • В карточке сотрудника динамика по дням разбита по категориям операций: каждый столбец - стек категорий.
  • Это интенсивность в активное время, а не продуктивность по табелю.

🧮 Формулы

Взвешенные операции = Σ (Кол-во операций × вес контекста)
КПД = Взвешенные операции / Активные слоты
Паллеты = Σ Кол-во операций, контекст = pallet
Штуки SKU = Σ Кол-во штук, контекст = sku
Сборки = Σ Кол-во операций, операция = «Сборка в заказы»
Заказы = Σ Кол-во операций, контекст = order
Активные часы = Уникальные (ЛДАП, дата, слот) × 10 / 60
Паллет/час = Паллеты / Активные часы паллетных строк
Штук SKU/час = Штуки SKU / Активные часы SKU-строк
Сборки/час = Сборки / Активные часы строк «Сборка в заказы»
Заказы/час = Заказы / Активные часы строк контекста order
Доля, % = Показатель / Итог по текущим фильтрам × 100

Вес зависит только от контекста операции. Несколько строк в одном 10-минутном интервале дают один активный слот.

    🧭 Вкладки

      🔎 Фильтры и правила

      • Период сверху действует на все вкладки, графики, карточки и таблицы.
      • Клик по столбцу гистограммы периода выбирает один день; ползунки и кнопки-пресеты задают диапазон.
      • Фильтры графиков и фильтры таблицы независимы друг от друга.
      • Доступны фильтры: контекст, тип подразделения, подразделение, должность, категория и операция; в таблице также поиск. Списки сужаются под остальные фильтры.
      • При переходе на другую вкладку фильтры сбрасываются.
      • Строки без ЛДАП или ФИО («нет данных») не попадают в топы и карточки сотрудников, но учитываются в общей динамике.
      • Порог слотов скрывает из топ-10 сотрудников с меньшим числом активных слотов. На графики и таблицу он не влияет.
      • Карта универсальности показывает, сколько категорий закрывает сотрудник. Фильтр категории на неё не влияет, остальные фильтры таблицы действуют.
      • Карточки категорий считают задействованных сотрудников; один человек может входить в несколько категорий.
