📥 Как получить данные из WMS Navision

  1. Откройте WMS Navision Глваное окно
  2. Перейдите по ссылке Нажмите на ссылку Содержимое ячеек (расширенное)
  3. Выделите данные Нажмите на любое место в списке и выделите всё с помощью сочетания клавишCtrl+A
  4. Скопируйте данные Нажмите пCtrl+Shift+C и дождитесь завершения копирования
  5. Выгрузите данные Создайте новый файл Excel и вставьте данные сочетанием кнопок Ctrl+V
  6. Сохраните файл Сохраните выгруженный файл в удобном месте на компьютере
  7. Загрузите в инструмент Перетащите файл Ваш_файл.xlsx в область загрузки, либо вставьте нажатием на область загрузки через проводник

Сохранение данных

Данные хранятся локально в браузере (IndexedDB) до ручной очистки. При обновлении страницы данные сохраняются.

Безопасность

Все данные обрабатываются локально в вашем браузере и не передаются на внешние серверы.

⚠️ Важно знать

Система обрабатывает ТОЛЬКО товары со статусом AVS = "Да" и заполненной датой AVS. Артикулы без даты в анализ и итоговый отчёт не попадают.

Экспорт из WMS Navision не всегда корректно работает при выгрузке большого количества строк, поэтому для надёжности необходимо использовать стандартные средства буфера windows через принудительное копирование всех строк.

Перед вставкой в таблицу необходимо отформатировать столбец где будут находиться sscc в текст - обычно это столбец S. Это необходимо чтобы внешние длинные sscc праильно отображались.
